# 🧠 Breast Cancer Classification with MLflow

This project demonstrates a complete machine learning workflow for classifying breast cancer tumors using the [Breast Cancer Wisconsin dataset](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html). It features hyperparameter tuning with `GridSearchCV`, model tracking with `MLflow`, and reproducible experiment logging.

---

## 🚀 Project Highlights

- ✅ **Random Forest Classifier** for robust performance
- 🔍 **GridSearchCV** for hyperparameter optimization
- 📊 **MLflow Tracking** for experiment management
- 📁 **Training/Test Data Logging** with lineage
- 🧪 **Nested Runs** for each hyperparameter trial
- 🏷️ **Tags, Metrics, Artifacts** for full traceability
